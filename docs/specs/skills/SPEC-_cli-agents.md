# _cli-agents
Agent-CLI interaction reference — generic procedures for driving another agent CLI in a tmux pane (spawn, pre-send validation, delivery probe, peek, await) plus a four-provider dictionary (claude, codex, agy, kimi) with stable invocation grammar and model-discovery recipes. Internal partial, opt-in via a consumer's `helpers:` frontmatter.
### Tools used
None — documents procedures its consumers execute (`fab agent`, `fab pane *`, `tmux` via Bash); the file itself runs nothing.
