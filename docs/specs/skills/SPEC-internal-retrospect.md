# internal-retrospect
Reviews the current session end-to-end and produces a retrospective across repetition, skill quality, context gaps, and workflow friction. Read-only and conversational; findings cite actual conversation moments.
## Flow
```
User invokes /internal-retrospect (agent reasoning over conversation history; no tool calls required)
└─ Output: per-area Findings (citations + suggested actions) or Clean → Suggested Actions, or "Clean session — no actions needed."
```
### Tools used
None — pure conversation analysis (may Read cited files to verify a claim).
### Sub-agents
None.
