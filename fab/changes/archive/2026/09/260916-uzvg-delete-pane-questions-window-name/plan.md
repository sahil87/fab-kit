### Design Decisions

#### Delete the verbs outright rather than hide or stub them
**Decision**: Remove `fab pane questions` and `fab pane window-name` from the binary, together with the `ReadWindowName` helper, with no alias or hidden stub.
**Why**: Both jobs moved to run-kit (`rk mux capture --classify`, `rk tab mark`/`note`) and the operator is spawned by `rk operator`, so run-kit is a hard dependency on that path; a verified census (kit skills, Go, run-kit) found zero consumers.
**Rejected**: Cobra hiding — a CLI surface change with tests and a standards audit for zero gain; keeping `window-name` as a dispatch primitive — `internal/dispatch.WindowName` only composes a string and never renames a window; keeping `questions` as an rk-absent fallback — the path it would serve no longer exists.
*Introduced by*: 260916-uzvg-delete-pane-questions-window-name

### Deprecated Requirements

#### `fab pane window-name ensure-prefix|replace-prefix`
**Reason**: Operator window marks ride `rk tab mark` / `rk tab note`; no caller remains.
**Migration**: N/A — use the run-kit verbs.

#### `fab pane questions`
**Reason**: Question detection rides `rk mux capture --classify`; no caller remains.
**Migration**: N/A — use `rk mux capture <pane> --classify --json`.
